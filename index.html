            Settings

            Gemini API key

            Free from aistudio.google.com/apikey — no credit card needed. Used only to read schedule screenshots. Stored on this device.

            Leave-by alerts

            Notifies you when it's time to walk. Only fires while this app is open.

            Display

            Bigger text and stronger contrast help when you're reading this in direct sun.

            Semester dates

            Optional. Outside this range ClassMapper stops pointing you at classes that aren't running yet, or are over.

            Offline mode

            Caches the app so it still opens with no signal — worth turning on once it's on your phone. Leave it off while you're setting things up, so you always get the newest version. If it ever misbehaves, open reset.html.

            Buildings

            — Tuskegee buildings from OpenStreetMap. Pins are building centres, so nudge any that aren't quite right.

            Your data

            Backs up your classes, building corrections, and preferences — not your API key, which stays only on this device. Everything lives in your browser's local storage, so back this up before clearing your browser data or switching phones.

            If the app ever looks broken or stuck on an old version, clear the offline cache. This keeps your classes — it only re-downloads the app files.
